WordPress 驱动了全球超过 40% 的网站，也是外贸独立站最主流的底座。在 **5F Framework（全球营销渔网架构）** 里，它是"建站技术"这一分支的根。

## 为什么外贸站首选 WordPress

- **生态成熟**：主题、页面构建器（Elementor 等）、表单、SEO 插件一应俱全，几乎不用从零造轮子。
- **内容友好**：文章/页面/分类天然适合做[内容营销](/flow/content/)与[内链建设](/flow/content/)，这正是 SEO 的基本盘。
- **所有权归你**：代码和数据都在自己服务器，不像 SaaS 建站被平台绑定。

## 关键决策点

1. **主题 vs 页面构建器**：新手用 Elementor 类可视化工具最快；追求性能可走轻量主题 + 区块。
2. **插件克制**：每个插件都是负担，只装必要的（缓存、SEO、表单、安全）。
3. **性能前置**：[Core Web Vitals](/framework/performance/core-web-vitals/) 从建站第一天就要管，否则后期补救成本高。

## 与 5F 的关系

WordPress 只是"网"的底网。真正织成获客渔网，还要接上[服务器与部署](/framework/hosting/)、再向上承接 [Flow 获客逻辑](/flow/) 里的 SEO 与社媒。当团队需要更高灵活性时，可平滑演进到 [Headless WordPress](/framework/site-tech/headless-wordpress/)。

> 选型没有绝对好坏，只有是否匹配你的团队与增长节奏——这正是 Focus 战略定力要回答的问题。
